- 1-1: git init erstellt ein Repository, git status zeigt den Zustand
- 1-2: git add stagt Änderungen, git commit speichert einen Snapshot
- 1-3: git log zeigt die Historie, git diff zeigt Änderungen
- 1-4: git restore verwirft Änderungen, git rm löscht, git mv verschiebt
