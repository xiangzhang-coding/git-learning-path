# 用語集

用語は必ず英語の原文を残します。この表は日本語での意味と初出の課を示します。

| 用語 | 意味 | 初出 |
| --- | --- | --- |
| repository | プロジェクトの履歴とメタデータを保存するディレクトリ（`.git` を含む） | 0-2 |
| working tree | 作業ツリー。ファイルを編集する場所 | 0-2 |
| staging area | ステージングエリア（別名 index）。次にコミットする変更の一覧 | 0-2 |
| commit | コミット。完全なスナップショットの記録 | 0-1 |
| snapshot | スナップショット。ある時点のプロジェクト全体の完全な状態 | 0-1 |
| SHA-1 | コンテンツハッシュ。commit の一意の識別子 | 段階 1 |
| HEAD | 現在のブランチの最新コミットを指すポインタ | 段階 2 |
| branch | ブランチ。移動できるコミットへのポインタ | 段階 2 |
| tag | タグ。特定のコミットに固定した名前 | 段階 4 |
| remote | リモート。別の場所に置かれたリポジトリのコピー | 段階 3 |
| origin | クローン時にデフォルトで付くリモート名 | 段階 3 |
| clone | クローン。リモートのリポジトリをローカルに複製する | 段階 3 |
| fetch | フェッチ。リモートのコミットをマージせずに取得する | 段階 3 |
| push | プッシュ。ローカルのコミットをリモートに送る | 段階 3 |
| pull | プル。fetch + merge | 段階 3 |
| merge | マージ。別のブランチを現在のブランチに統合する | 段階 2 |
| rebase | リベース。コミットを新しい基盤に付け替える | 段階 4 |
| conflict | コンフリクト。重なる変更で手動解決が必要な状態 | 段階 2 |
| stash | スタッシュ。未コミットの変更を一時的に退避する | 段階 4 |
| checkout | チェックアウト。ブランチの切り替えやファイルの復元 | 段階 2 |
| switch | スイッチ。ブランチを切り替える（新しいコマンド） | 段階 2 |
| restore | リストア。ファイルをあるバージョンへ戻す | 段階 1 |
| reset | リセット。HEAD やステージングエリア／作業ツリーを動かす | 段階 4 |
| revert | リバート。新しいコミットで古いコミットを取り消す | 段階 4 |
| cherry-pick | チェリーピック。特定のコミットを現在のブランチに複製する | 段階 4 |
| diff | ディフ。2 つの状態の間の変更 | 段階 1 |
| status | ステータス。3 つのエリア間の差分の概観 | 段階 1 |
| log | ログ。コミット履歴の一覧 | 段階 1 |
| tracking branch | トラッキングブランチ。リモートブランチと関連づいたローカルブランチ | 段階 3 |
| upstream | アップストリーム。ローカルブランチが追跡するリモートブランチ | 段階 3 |
| fast-forward | ファストフォワード。分岐なしで前へ進むだけのマージ | 段階 2 |
| detached HEAD | デタッチド HEAD。HEAD がどのブランチも指していない状態 | 段階 4 |
| reflog | リフログ。HEAD が移動した完全な記録 | 段階 4 |
| DAG | 有向非巡回グラフ。コミット履歴のトポロジー | 段階 2 |
| fork | フォーク。他人のリポジトリを自分のアカウントへ複製する | 段階 5 |
| pull request | プルリクエスト（PR）。ブランチの統合を依頼する | 段階 5 |
| issue | イシュー。リポジトリ内で bug・機能・タスクをめぐる議論スレッド | 段階 5 |
| milestone | マイルストーン。複数の issue を同じバージョン目標にまとめる | 段階 5 |
| release | リリース。tag を基にした正式バージョンで、説明と成果物を添える | 段階 5 |
| workflow | ワークフロー。GitHub Actions の自動化フロー | 段階 5 |
