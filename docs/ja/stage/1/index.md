# 章 1 — ローカル基礎

この章の原理の主線：**スナップショットと SHA**。この章のすべてのコマンドは、本質的に3つのエリアの間でコンテンツを運ぶ操作です。

- 1-1：git init でリポジトリを作成、git status でリポジトリの状態を読み取る
- 1-2：git add でステージ、git commit でスナップショットを保存
- 1-3：git log で履歴を確認、git diff で変更を確認
- 1-4：git restore で取り消し、git rm で削除、git mv で移動

各課の末尾にある練手区にはコマンドを直接入力でき、タスク問題が結果を自動でチェックします。
