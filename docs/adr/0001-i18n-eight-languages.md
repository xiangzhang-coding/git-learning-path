# 全站 8 语言 i18n，术语保留英文原文

课程站面向公众发布，首版即上线 8 种语言（中/英/日/韩/德/法/西/葡/俄），根路径按浏览器语言自动重定向并可用 Cookie 记住选择（语言跟随）。选择了「每种语言一套内容」而非单语言或 zh/en 双语的路线，因为目标读者是任意语言的开发者；代价是内容变更时全量同步翻译，靠「术语保留英文原文 + 每语言术语表」保证一致性，AI 初译 + 逐语言精修轮兜底质量。

- **Status**: accepted
- **Considered Options**: 仅中文（放弃公开价值）；zh/en 双语（与首版 8 语言要求冲突）
- **Consequences**: 内容迭代成本 ×8；需要术语表作为一致性锚点；根路径重定向依赖客户端 JS（GitHub Pages 无服务端重定向）
