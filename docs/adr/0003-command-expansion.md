# 扩展 4 个排查类命令，全部进练手区

课程扩展了 4 个命令：`git show`（查看单个提交详情）、`git blame`（逐行追责）、`git clean`（清理未跟踪文件）、`git bisect`（二分定位坏提交）。全部实现练手区引擎（可执行 + 场景 + 任务检查），而非只做概念课。

- **Status**: accepted
- **Considered Options**: 只做概念课（与课程「可动手」特色脱节）；不扩展（错过高频排查命令）；bisect 不进（低频、引擎成本高——用户明确要求全引入）
- **Consequences**: 引擎新增 4 个命令 + 2 个新场景（clean、bisect）+ 2 个新 check 类型（workdirClean、bisectDone）；1-3 并入 show/blame、4-2 并入 clean、4-3 并入 bisect（不新增课，保持章节结构）；9 语言全量同步

落位原则（Q12 决策）：命令并入同主题课的既有小节——查历史主题 → 章节 1 的 1-3；撤销/清理主题 → 4-2；修复/定位主题 → 4-3。符合「课覆盖 2–4 个常用命令」的范围原则。
