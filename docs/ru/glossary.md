# Глоссарий

Термины всегда сохраняют английское название; эта таблица даёт краткое объяснение.

| Термин | Значение | Первое появление |
| --- | --- | --- |
| repository | Директория, хранящая историю и метаданные (содержит `.git`) | 0-2 |
| working tree | Область, где вы редактируете файлы | 0-2 |
| staging area | Список изменений, подготовленных к следующему коммиту (также index) | 0-2 |
| commit | Полная запись-снимок | 0-1 |
| snapshot | Полное состояние проекта в момент времени | 0-1 |
| SHA-1 | Хеш содержимого; уникальный идентификатор коммита | Глава 1 |
| HEAD | Указатель на последний коммит текущей ветки | Глава 2 |
| branch | Перемещаемый указатель на коммит | Глава 2 |
| tag | Имя, закреплённое за конкретным коммитом | Глава 4 |
| remote | Копия репозитория, размещённая в другом месте | Глава 3 |
| origin | Имя remote по умолчанию после clone | Глава 3 |
| clone | Копирование удалённого репозитория на свою машину | Глава 3 |
| fetch | Загрузка удалённых коммитов без слияния | Глава 3 |
| push | Загрузка локальных коммитов в remote | Глава 3 |
| pull | fetch + merge | Глава 3 |
| merge | Интеграция другой ветки в текущую | Глава 2 |
| rebase | Пересадка коммитов на новую основу | Глава 4 |
| conflict | Пересекающиеся изменения, требующие ручного разрешения | Глава 2 |
| stash | Временное откладывание незакоммиченных изменений | Глава 4 |
| checkout | Переключение веток или восстановление файлов | Глава 2 |
| switch | Переключение веток (более новая команда) | Глава 2 |
| restore | Восстановление файла до заданной версии | Глава 1 |
| reset | Перемещение HEAD и/или staging area и working tree | Глава 4 |
| revert | Отмена старого коммита новым коммитом | Глава 4 |
| cherry-pick | Копирование конкретного коммита в текущую ветку | Глава 4 |
| diff | Изменение между двумя состояниями | Глава 1 |
| status | Обзор различий между тремя областями | Глава 1 |
| log | Список истории коммитов | Глава 1 |
| tracking branch | Локальная ветка, связанная с удалённой | Глава 3 |
| upstream | Удалённая ветка, за которой следует локальная | Глава 3 |
| fast-forward | Слияние, просто продвигающееся вперёд без расхождения | Глава 2 |
| detached HEAD | HEAD, не указывающий ни на одну ветку | Глава 4 |
| reflog | Полная запись всех положений HEAD | Глава 4 |
| DAG | Ориентированный ациклический граф; топология истории | Глава 2 |
| fork | Копирование чужого репозитория в свой аккаунт | Глава 5 |
| pull request | Запрос на слияние вашей ветки (PR) | Глава 5 |
| issue | Ветка обсуждения конкретной проблемы (баг, фича, задача) | Глава 5 |
| label | Метка для классификации issues (например, bug, enhancement) | Глава 5 |
| milestone | Группа issues, объединённая целью одной версии | Глава 5 |
| release | Официальный выпуск на основе tag, с описанием и файлами | Глава 5 |
| workflow | Автоматизированный процесс GitHub Actions | Глава 5 |
