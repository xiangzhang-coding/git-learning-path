# Глоссарий

Термины всегда сохраняют английское название; эта таблица даёт краткое объяснение.

| Термин | Значение | Первое появление |
| --- | --- | --- |
| repository | Директория, хранящая историю и метаданные (содержит `.git`) | 0-2 |
| working tree | Область, где вы редактируете файлы | 0-2 |
| staging area | Список изменений, подготовленных к следующему коммиту (также index) | 0-2 |
| commit | Полная запись-снимок | 0-1 |
| snapshot | Полное состояние проекта в момент времени | 0-1 |
| SHA-1 | Хеш содержимого; уникальный идентификатор коммита | Этап 1 |
| HEAD | Указатель на последний коммит текущей ветки | Этап 2 |
| branch | Перемещаемый указатель на коммит | Этап 2 |
| tag | Имя, закреплённое за конкретным коммитом | Этап 4 |
| remote | Копия репозитория, размещённая в другом месте | Этап 3 |
| origin | Имя remote по умолчанию после clone | Этап 3 |
| clone | Копирование удалённого репозитория на свою машину | Этап 3 |
| fetch | Загрузка удалённых коммитов без слияния | Этап 3 |
| push | Загрузка локальных коммитов в remote | Этап 3 |
| pull | fetch + merge | Этап 3 |
| merge | Интеграция другой ветки в текущую | Этап 2 |
| rebase | Пересадка коммитов на новую основу | Этап 4 |
| conflict | Пересекающиеся изменения, требующие ручного разрешения | Этап 2 |
| stash | Временное откладывание незакоммиченных изменений | Этап 4 |
| checkout | Переключение веток или восстановление файлов | Этап 2 |
| switch | Переключение веток (более новая команда) | Этап 2 |
| restore | Восстановление файла до заданной версии | Этап 1 |
| reset | Перемещение HEAD и/или staging area и working tree | Этап 4 |
| revert | Отмена старого коммита новым коммитом | Этап 4 |
| cherry-pick | Копирование конкретного коммита в текущую ветку | Этап 4 |
| diff | Изменение между двумя состояниями | Этап 1 |
| status | Обзор различий между тремя областями | Этап 1 |
| log | Список истории коммитов | Этап 1 |
| tracking branch | Локальная ветка, связанная с удалённой | Этап 3 |
| upstream | Удалённая ветка, за которой следует локальная | Этап 3 |
| fast-forward | Слияние, просто продвигающееся вперёд без расхождения | Этап 2 |
| detached HEAD | HEAD, не указывающий ни на одну ветку | Этап 4 |
| reflog | Полная запись всех положений HEAD | Этап 4 |
| DAG | Ориентированный ациклический граф; топология истории | Этап 2 |
| fork | Копирование чужого репозитория в свой аккаунт | Этап 5 |
| pull request | Запрос на слияние вашей ветки (PR) | Этап 5 |
