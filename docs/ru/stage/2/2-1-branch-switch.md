# git branch и git switch

## Цели урока

- Просматривать и создавать ветки с помощью git branch
- Переключаться между ветками с помощью git switch
- Понимать, что branch — это указатель, а HEAD отмечает текущее положение

## Branch указывает на коммит

Branch по своей сути — это **перемещаемый указатель на commit**. Создание ветки ничего не копирует: появляется лишь имя, указывающее на текущий commit:

```bash
git branch feature
```

Эта команда записывает в репозиторий имя `feature`, указывающее на commit, где находится HEAD. После этого вы коммитите на `feature` — и указатель feature продвигается вперёд.

**Ключевая мысль: у ветки нет «своего кода»** — это лишь метка положения в истории. Один и тот же рабочий каталог, но под другим именем ветки: вы видите снимок, на который указывает этот указатель.

## git branch: просмотр и создание веток

```bash
git branch        # список всех веток, текущая отмечена *
git branch <имя>  # создать ветку (без переключения)
```

Вывод списка выглядит так:

```
* main
  feature
```

Создание ветки лишь фиксирует указатель — **переключение не происходит**. Чтобы перейти на неё, используйте switch.

## git switch: переключение веток

```bash
git switch <имя>      # переключиться на существующую ветку
git switch -c <имя>   # создать и переключиться (самый частый вариант)
```

- `git switch feature`: HEAD переходит на `feature`, файлы рабочего каталога заменяются снимком этой ветки
- `git switch -c feature`: создаёт новую ветку и сразу переключается на неё — то же, что `git branch feature` + `git switch feature`

**Старый синтаксис**: `git checkout <имя>` и `git checkout -b <имя>` — старые команды с тем же действием; `git switch` — новая рекомендованная команда, зона практики поддерживает обе. У `git checkout` также есть применение «восстановление файлов», которое теперь выполняет `git restore` (глава 1).

Если в рабочем каталоге есть незакоммиченные изменения, git откажется переключаться и попросит сначала закоммитить или отложить их (stash) — при смене снимка изменениям просто негде будет находиться.

## HEAD указывает на текущее положение

**HEAD** — это специальный указатель, отмечающий «на каком commit какой ветки вы находитесь». Строка `On branch feature` в начале вывода git status — это и есть ответ HEAD. Переключение ветки — это перемещение указателя HEAD.
