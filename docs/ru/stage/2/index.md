# Глава 2 — Ветки и слияние

Принципиальная линия этой главы: **коммит-граф и HEAD**. Branch — это просто указатель на commit, а HEAD отмечает ваше текущее положение; все операции с ветками (switch, merge, конфликт) — это перемещение указателей по коммит-графу или смыкание разошедшихся линий истории.

## Уроки

- 2-1 [git branch и git switch](/ru/stage/2/2-1-branch-switch): branch — это указатель, HEAD — текущее положение
- 2-2 [Работа на ветке](/ru/stage/2/2-2-branch-workflow): коммиты попадают только в текущую ветку, история расходится в DAG
- 2-3 [git merge — слияние веток](/ru/stage/2/2-3-merge): fast-forward и merge commit
- 2-4 [Разрешение merge conflict](/ru/stage/2/2-4-merge-conflict): маркеры конфликта и порядок разрешения

## Новые команды главы

| Команда | Что делает |
| --- | --- |
| `git branch` | Показать список веток, текущая помечена `*` |
| `git branch <name>` | Создать ветку (без переключения) |
| `git switch <name>` | Переключиться на существующую ветку |
| `git switch -c <name>` | Создать ветку и сразу переключиться на неё |
| `git merge <branch>` | Влить целевую ветку в текущую |
