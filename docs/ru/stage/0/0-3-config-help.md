# config и help

## Цели урока

- Настроить user.name и user.email
- Понять уровни system / global / local
- Научиться искать команды через help

## Настройка перед первым коммитом

Git должен знать автора каждого коммита — настройте один раз:

```bash
git config --global user.name "Ваше имя"
git config --global user.email "вы@example.com"
```

`--global` действует для всех репозиториев. `git config --list` показывает всю действующую конфигурацию, `git config user.name` — одну запись.

## Три уровня конфигурации

У конфигурации три уровня — **чем конкретнее, тем выше приоритет**:

| Уровень | Область | Где хранится |
| --- | --- | --- |
| system | все пользователи машины | `/etc/gitconfig` |
| global | все репозитории пользователя | `~/.gitconfig` |
| local | текущий репозиторий | `.git/config` |

Действующее значение определяется в порядке local → global → system.

## Когда вы встретили незнакомую команду

- `git help <команда>`: открывает полное руководство
- `git <команда> -h`: быстрое краткое описание
- `git help --all`: список всех команд

Забыть команду — не проблема; достаточно знать, как её найти.
