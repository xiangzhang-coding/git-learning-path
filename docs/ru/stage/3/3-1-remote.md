# git remote — удалённый репозиторий

## Цели урока

- Понять, что такое remote: расположение другой копии репозитория
- Зарегистрировать remote командой git remote add
- Посмотреть настройку командой git remote -v

## Что такое remote

До сих пор все ваши коммиты жили только в **одной копии репозитория на вашей машине**. В настоящих проектах работают несколько человек: у каждого своя копия, а ещё есть «общий репозиторий», через который они обмениваются изменениями, — это и есть remote.

remote (удалённый репозиторий) — это по сути **адрес другого git-репозитория**. У git нет никакого «облака»: любая машина (или даже каталог) может выступать в роли remote. Вы ссылаетесь на него по имени, и по умолчанию это имя — **origin** (его автоматически присваивает clone).

В зоне практики этого урока `/origin` — это и есть адрес удалённого репозитория: отдельная от локального `/repo` копия в памяти. **В remote нельзя зайти через `cd`**: в нём только история, нет рабочего дерева (как в настоящем bare-репозитории или репозитории на сервере). Вы работаете со своей локальной копией, а с ним обмениваетесь данными командами git.

## git remote: просмотр и добавление

```bash
git remote            # перечислить имена remote
git remote -v         # перечислить имена + адреса (по строке для fetch и push)
git remote add <имя> <адрес>   # зарегистрировать новый remote
```

```
$ git remote -v
origin  /origin  (fetch)
origin  /origin  (push)
```

`remote add` только регистрирует адрес и **не передаёт никаких данных**. Он записывает настройку в `.git/config`:

```
[remote "origin"]
	url = /origin
	fetch = +refs/heads/*:refs/remotes/origin/*
```

## Запомните две роли

| Имя | Значение |
| --- | --- |
| Локальная ветка | `refs/heads/main`, сюда попадают ваши коммиты |
| remote | адрес удалённого репозитория, например `/origin` |
| tracking branch | `refs/remotes/origin/main`, локальное зеркало того, «на что указывает main на удалённой стороне» |

Tracking branch — ключ к следующим урокам clone/fetch: она позволяет видеть, «как выглядит remote», даже без сети.
