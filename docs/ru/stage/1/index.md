# Этап 1 — Локальные основы

Принципиальная линия этого этапа: **снимки и SHA**. Все команды этого этапа по сути переносят содержимое между тремя областями.

- 1-1: git init создаёт репозиторий, git status показывает состояние репозитория
- 1-2: git add подготавливает изменения, git commit сохраняет снимок
- 1-3: git log показывает историю, git diff показывает изменения
- 1-4: git restore отменяет изменения, git rm удаляет файлы, git mv перемещает файлы

В тренажёре в конце каждого урока можно напрямую вводить команды; задания автоматически проверяют ваш результат.
