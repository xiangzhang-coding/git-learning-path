# Etapa 1 — Fundamentos locales

El hilo de principios de esta etapa: **instantáneas y SHA**. Todo lo que hacen los comandos de esta etapa es, en el fondo, mover contenido entre las tres áreas.

- 1-1: git init crea el repositorio; git status descifra el estado del repositorio
- 1-2: git add prepara; git commit guarda la instantánea
- 1-3: git log muestra el historial; git diff muestra los cambios
- 1-4: git restore revierte; git rm elimina; git mv mueve

En la zona de práctica del final de cada lección puedes escribir comandos directamente, y las tareas comprueban tu resultado automáticamente.
