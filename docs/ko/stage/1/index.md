# 단계 1 — 로컬 기초

이 단계의 원리 축: **스냅샷과 SHA**. 이 단계의 모든 명령은 본질적으로 세 영역 사이에서 내용을 옮기는 일입니다.

- 1-1: git init으로 저장소를 만들고, git status로 저장소 상태를 읽는다
- 1-2: git add로 스테이징하고, git commit으로 스냅샷을 저장한다
- 1-3: git log로 기록을 보고, git diff로 변경을 본다
- 1-4: git restore로 되돌리고, git rm으로 삭제하고, git mv로 이동한다

각 과 끝의 연습장에는 명령을 바로 입력할 수 있으며, 과제형 연습은 결과를 자동으로 확인해 줍니다.
