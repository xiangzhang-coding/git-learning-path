# Etapa 1 — Fundamentos locais

A linha de princípios desta etapa: **snapshot e SHA**. Todos os comandos desta etapa, no fundo, movem conteúdo entre as três áreas.

- 1-1: git init cria repositórios, git status lê o estado do repositório
- 1-2: git add prepara, git commit salva snapshots
- 1-3: git log mostra o histórico, git diff mostra as mudanças
- 1-4: git restore desfaz, git rm exclui, git mv move

A zona de prática no fim de cada lição aceita comandos diretamente, e as tarefas verificam o resultado automaticamente.
