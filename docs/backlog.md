已确认但暂不实现的改进想法，按优先级排序。

## 章节回顾页（已确认有价值，低优先）

每章节末增加一个「本章回顾」小节：5–6 道概念选择题，串起该章节的原理主线。不设提交门槛（与练习一致）。落位：各语言 `stage/N/index.md` 或独立页面。

## URL 从 /stage/ 重命名为 /chapter/（已确认暂不改）

界面术语已改为「章节」，但 URL 仍为 `/stage/`。改名的收益仅是 URL 美观，成本包括：全部站内链接、进度 localStorage 数据、PageFind 索引、外部书签。若未来做 2.0 大改版可一并处理。

## 进度云同步（已确认放弃）

localStorage 进度不跨设备。云同步需要后端，违背纯静态部署约束。默认不跨设备。
