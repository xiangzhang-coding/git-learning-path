# Glossary

Terms always keep their English names; this table gives a short definition for each.

| Term | Meaning | First seen |
| --- | --- | --- |
| repository | The directory that stores project history and metadata (contains `.git`) | 0-2 |
| working tree | The area where you edit files | 0-2 |
| staging area | The list of changes prepared for the next commit (also called index) | 0-2 |
| commit | A complete snapshot record | 0-1 |
| snapshot | The complete state of the project at one point in time | 0-1 |
| SHA-1 | Content hash; the unique identifier of a commit | Chapter 1 |
| HEAD | Pointer to the latest commit of the current branch | Chapter 2 |
| branch | A movable pointer to a commit | Chapter 2 |
| tag | A name fixed to a specific commit | Chapter 4 |
| remote | A copy of the repository hosted elsewhere | Chapter 3 |
| origin | The default name of the remote after cloning | Chapter 3 |
| clone | Copy a remote repository to your machine | Chapter 3 |
| fetch | Download remote commits without merging | Chapter 3 |
| push | Upload local commits to a remote | Chapter 3 |
| pull | Fetch + merge | Chapter 3 |
| merge | Integrate another branch into the current one | Chapter 2 |
| rebase | Re-anchor commits onto a new base | Chapter 4 |
| conflict | Overlapping changes that need manual resolution | Chapter 2 |
| stash | Set aside uncommitted changes temporarily | Chapter 4 |
| checkout | Switch branches or restore files | Chapter 2 |
| switch | Switch branches (newer command) | Chapter 2 |
| restore | Restore a file to a given version | Chapter 1 |
| reset | Move HEAD and/or the staging area and working tree | Chapter 4 |
| revert | Undo an old commit with a new commit | Chapter 4 |
| cherry-pick | Copy a specific commit onto the current branch | Chapter 4 |
| diff | The change between two states | Chapter 1 |
| status | Overview of the differences between the three areas | Chapter 1 |
| log | The list of commit history | Chapter 1 |
| tracking branch | A local branch associated with a remote branch | Chapter 3 |
| upstream | The remote branch a local branch tracks | Chapter 3 |
| fast-forward | A merge that just moves forward without divergence | Chapter 2 |
| detached HEAD | HEAD not pointing at any branch | Chapter 4 |
| reflog | The complete record of where HEAD has been | Chapter 4 |
| DAG | Directed acyclic graph; the topology of commit history | Chapter 2 |
| fork | Copy someone else's repository into your account | Chapter 5 |
| pull request | Request to merge your branch (PR) | Chapter 5 |
| issue | Discussion thread for bugs, features, and tasks | Chapter 5 |
| label | Category tag on an issue, e.g. bug or enhancement | Chapter 5 |
| milestone | Group issues under one version goal | Chapter 5 |
| release | Official version built on a tag, with notes and assets | Chapter 5 |
| workflow | The automated process of GitHub Actions | Chapter 5 |
